# Exercício Sistema de Pagamento em Csharp

Repositório destinado aos exercícios e estudos realizados durante o bootcamp da **WoMakersCode** ✨

Os exercícios deste repositório abordam os fundamentos da programação utilizando a linguagem **C#** e Orientação a objeto.

## Módulo 5 — Programação Orientada a Objeto com C#

| Conteúdo | Descrição |
| --- | --- |
| Introdução à POO | Conceitos fundamentais e os pilares que sustentam a Programação Orientada a Objetos. |
| Classes e Objetos | Criação de moldes (classes) e a instanciação de entidades do mundo real (objetos). |
| Atributos e Métodos | Definição das características (dados) e dos comportamentos (ações) de uma classe |
| Encapsulamento | Proteção de dados e controle de acesso utilizando modificadores e propriedades `(get/set)`. |
| Herança | Mecanismo de reutilização de código onde uma classe filha herda características de uma classe pai. |
| Polimorfismo | Capacidade de um método se comportar de diferentes formas através de sobrescrita `(override)`. |
| Classes e Métodos Abstratos | Contratos e classes bases que não podem ser instanciadas diretamente, servindo apenas de modelo. |
| Interfaces | Definição de contratos que classes devem implementar, garantindo padronização e desacoplamento. |

## Tecnologias utilizadas

- C#
- .NET
- Visual Studio Code
